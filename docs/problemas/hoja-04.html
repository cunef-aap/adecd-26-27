Hoja 4

Hoja del capítulo 4, Evaluar para generalizar: métricas, línea base, particiones, K-fold cross validation y el sesgo de seleccionar con los mismos datos. El capítulo ocupa dos semanas, así que la hoja se reparte entre las dos sesiones de problemas, y cada bloque tiene ejercicios de las dos mitades. Los cuatro primeros bloques tienen la estructura del examen.

Sesión Ejercicios
Primera, métricas y línea base Ejercicio 1, Ejercicio 2, Ejercicio 4, Ejercicio 5, Ejercicio 6, Ejercicio 13, Ejercicio 14, Ejercicio 19
Segunda, particiones, selección y validación cruzada los demás

import numpy as np
from sklearn.linear_model import LinearRegression

X, y = cargar_datos()                      # 97 observaciones, 8 variables
X_train, X_test, y_train, y_test = separar(X, y, n_test=30)

mejor = None
for m in range(1, 9):
    modelo = LinearRegression().fit(X[:, :m], y)
    error = np.mean((y_test - modelo.predict(X_test[:, :m])) ** 2)
    if mejor is None or error < mejor[1]:

print("variables elegidas:", mejor[0])
