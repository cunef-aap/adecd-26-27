Hoja 1

Hoja del capítulo 1, Datos = señal + ruido. El capítulo ocupa dos semanas, así que la hoja se reparte entre las dos sesiones de problemas. Los cuatro primeros bloques tienen la estructura del examen; el de completar código es de laboratorio y el último es de ampliación.

1. Conceptual

Bloque A del examen. Respuesta breve, tres o cuatro frases cada apartado.

Ejercicio 1  

  1. Una empresa quiere predecir el consumo eléctrico de un edificio a partir de la temperatura, la hora y el día de la semana. Identifica los predictores \(\mathbf{x}\), la respuesta \(y\), una posible fuente de señal y dos posibles fuentes de ruido.
  2. Explica la diferencia entre \(f(\mathbf{x})\), \(y\) y \(\widehat y\) en el modelo señal más ruido. ¿Cuál de las tres queremos aprender y cuáles observamos?
  3. Un compañero afirma que, como \(\mathbb{E}\!\left[ \varepsilon\,\vert\,X \right]=0\), cada observación debe estar exactamente sobre la señal. Corrige la afirmación e interpreta bien la hipótesis.
  4. Otro compañero te enseña un modelo con error de entrenamiento cero y te dice que ha resuelto el problema. Razona qué le contestarías, citando el resultado del capítulo en el que te apoyas.

Ejercicio 2 El modelo lineal-gaussiano supone que la señal es una recta y que el ruido es normal, de media cero y de la misma desviación típica para todas las observaciones.

  1. Razona si ese modelo es el proceso que genera los datos o una hipótesis nuestra sobre él, y qué diferencia hay entre las dos cosas.
  2. Para cada una de estas situaciones, di qué supuesto del modelo se rompe: el precio de una vivienda crece con la superficie pero cada vez más despacio; la variabilidad de las ventas es mucho mayor en diciembre que en marzo; dos mediciones consecutivas del mismo sensor tienden a errar en el mismo sentido.
  3. Explica por qué que un supuesto se rompa no impide ajustar el modelo, y qué es lo que sí limita.

4. Encuentra los errores

Bloque D. Se puntúa la justificación de cada error.

Ejercicio 10 Este fragmento pretende aprender la señal de unos datos. Contiene tres errores conceptuales. Localízalos y explica la consecuencia de cada uno.

import numpy as np

x = np.arange(5)
y = np.array([1.2, 2.7, 5.4, 6.5, 9.1])

# la señal verdadera es la lista de valores observados
senal = y

def predict(x_nuevo):
    # devolvemos la respuesta del punto conocido más cercano
    i = np.argmin(np.abs(x - x_nuevo))
    return y[i]

# como reproduce los datos, hemos demostrado que aprende
print(np.allclose([predict(xi) for xi in x], y))

Ejercicio 11 El siguiente fragmento pretende comparar dos modelos y quedarse con el mejor. Tiene tres errores conceptuales. Localízalos y explica en cada caso qué consecuencia tiene.

import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures

X, y = cargar_datos()                      # 40 observaciones

Phi = PolynomialFeatures(degree=39).fit_transform(X)
modelo_a = LinearRegression().fit(Phi, y)
modelo_b = LinearRegression().fit(X, y)

error_a = np.mean((y - modelo_a.predict(Phi)) ** 2)
error_b = np.mean((y - modelo_b.predict(X)) ** 2)

print("gana el modelo a" if error_a < error_b else "gana el modelo b")
