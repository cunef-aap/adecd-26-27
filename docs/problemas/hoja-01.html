Hoja 1

Hoja del capítulo 1, Datos = señal + ruido. El capítulo ocupa dos semanas, así que la hoja se reparte entre las dos sesiones de problemas. Los cuatro primeros bloques tienen la estructura del examen; el de completar código es de laboratorio y el último es de ampliación.

Todo el código que aparece en los bloques A a D sale de los seis fragmentos que el capítulo marca como se explica en clase. No hace falta recordar la firma de ninguna función: la que no se haya visto en clase va explicada en el propio enunciado.

4. Encuentra los errores

Bloque D. Se puntúa la justificación de cada error.

Ejercicio 11 Este fragmento pretende aprender la señal de unos datos. Contiene tres errores conceptuales. Localízalos y explica la consecuencia de cada uno.

import torch

x = torch.linspace(0, 4, 5)
y = torch.tensor([1.2, 2.7, 5.4, 6.5, 9.1])

# la señal del proceso
senal = y

def predice(x_nuevo):
    # .argmin() da la posición del valor más pequeño de un tensor,
    # así que i es el punto conocido más cercano a x_nuevo
    i = (x - x_nuevo).abs().argmin()
    return y[i]

prediccion = torch.tensor([predice(xi) for xi in x])
error = ((prediccion - y) ** 2).mean()

# error cero: el modelo ha aprendido la señal
print(error.item())

Ejercicio 12 El siguiente fragmento pretende comparar dos modelos y quedarse con el mejor. Tiene tres errores conceptuales. Localízalos y explica en cada caso qué consecuencia tiene.

import torch

x = torch.linspace(0, 10, 20)
y = 2 * x + 1 + 3 * torch.randn(20)

# modelo A: la recta
pred_a = 2 * x + 1
# modelo B: repetir cada respuesta observada
pred_b = y

error_a = ((y - pred_a) ** 2).mean()
error_b = ((y - pred_b) ** 2).mean()

print("gana B" if error_b < error_a else "gana A")
