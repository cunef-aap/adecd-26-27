Capítulo 2, Señal y ruido. Los cuatro primeros ejercicios son nucleares y tienen la estructura del examen; el quinto es de ampliación.

1. Conceptual

Bloque A del examen. Respuesta breve, tres o cuatro frases cada apartado.

Ejercicio 1  

  1. Un compañero te enseña un modelo con error de entrenamiento cero y te dice que ha resuelto el problema. Razona qué le contestarías, citando el resultado del capítulo en el que te apoyas.
  2. Explica en qué se diferencian la señal y el ruido en el modelo \(y_i= f(\mathbf{x}_i) + \varepsilon_i\), y cuál de los dos queremos aprender.
  3. Analiza la siguiente afirmación: “como el ruido tiene media cero, con suficientes datos desaparece y podemos recuperar \(f\) exactamente”.
  1. Que no es evidencia de nada. Por Teorema 2.1, con abscisas distintas siempre existe un polinomio que interpola los datos exactamente, de modo que un error de entrenamiento nulo se puede conseguir siempre y no distingue un modelo bueno de uno malo. La pregunta pertinente es qué error comete sobre observaciones que no se hayan usado para ajustarlo.
  2. La señal es la parte de \(y\) que depende sistemáticamente de \(\mathbf{x}\), es decir \(f\); el ruido es la parte que varía entre observaciones con el mismo \(\mathbf{x}\). Queremos aprender \(f\). Ajustar también el ruido es precisamente el sobreajuste de
  3. Es falsa tal como está enunciada. Que \(\mathbb{E}\!\left[ \varepsilon_i \right]=0\) no implica que el ruido desaparezca en una observación concreta: cada \(y\) nuevo trae su propio \(\varepsilon\). Con más datos podemos estimar \(f\) mejor, pero el error de predicción sobre una observación nueva no baja de \(\mathrm{Var}\!\left( \varepsilon \right)\). Ese suelo es el ruido irreducible del capítulo 7.

2. Demostración

Bloque B. Es del índice de resultados, así que puede caer tal cual en el examen.

Ejercicio 2 Sean \(x_1,\dots,x_{n}\) distintos dos a dos.

  1. Escribe la base de Lagrange \(\ell_j\) y comprueba que \(\ell_j(x_i) = \delta_{ij}\).
  2. Demuestra Teorema 2.1: existe un polinomio de grado \(\leq n-1\) que pasa por los \(n\) puntos.
  3. Constrúyelo explícitamente para \((1,3)\), \((2,5)\) y \((4,2)\), y comprueba que pasa por los tres.

a y b están en Teorema 2.1.

  1. Con \(x_1=1\), \(x_2=2\), \(x_3=4\): \[ \ell_1(x) = \frac{(x-2)(x-4)}{(1-2)(1-4)} = \frac{(x-2)(x-4)}{3}, \quad \ell_2(x) = \frac{(x-1)(x-4)}{(2-1)(2-4)} = -\frac{(x-1)(x-4)}{2}, \] \[ \ell_3(x) = \frac{(x-1)(x-2)}{(4-1)(4-2)} = \frac{(x-1)(x-2)}{6}. \] El polinomio es \(P(x) = 3\ell_1(x) + 5\ell_2(x) + 2\ell_3(x)\). Comprobación: \(P(1) = 3\cdot 1 + 5\cdot 0 + 2\cdot 0 = 3\), y análogamente \(P(2)=5\) y \(P(4)=2\).

3. Cálculo a mano

Bloque C. Sin calculadora; los números están elegidos para que salgan redondos.

Ejercicio 3 Se ajustan dos modelos sobre estas cuatro observaciones de entrenamiento:

\(x\) 1 2 3 4
\(y\) 2 4 5 9

El modelo \(A\) predice \(\hat{y}= 2x\). El modelo \(B\) predice \(\hat{y}= 2, 4, 5, 9\) respectivamente, es decir, interpola.

  1. Calcula el error de entrenamiento \(\hat{R}\) de cada modelo.
  2. Llegan dos observaciones nuevas: \((x,y) = (2, 3)\) y \((x,y) = (3, 7)\). El modelo \(B\) predice sobre ellas lo mismo que predecía en entrenamiento para esos valores de \(x\). Calcula el error de test de cada modelo.
  3. ¿Qué modelo elegirías y por qué? Relaciona la respuesta con 1.
  1. Modelo \(A\): residuos \(2-2=0\), \(4-4=0\), \(5-6=-1\), \(9-8=1\). Suma de cuadrados \(=2\), luego \(\hat{R}_A = 2/4 = 0{,}5\). Modelo \(B\): todos los residuos son cero, \(\hat{R}_B = 0\).
  2. Modelo \(A\) sobre test: predice \(4\) y \(6\); residuos \(3-4=-1\) y \(7-6=1\); suma \(=2\), \(\hat{R}_A^{\text{test}} = 2/2 = 1\). Modelo \(B\): predice \(4\) y \(5\); residuos \(-1\) y \(2\); suma \(=1+4=5\), \(\hat{R}_B^{\text{test}} = 5/2 = 2{,}5\).
  3. El modelo \(A\). \(B\) gana en entrenamiento (0 frente a 0,5) y pierde en test (2,5 frente a 1): es exactamente el patrón de 1, aumentar la complejidad mejora el error de entrenamiento y empeora el de test.

4. Encuentra los errores

Bloque D. Se puntúa la justificación, no la lista.

Ejercicio 4 El siguiente fragmento pretende comparar dos modelos y quedarse con el mejor. Tiene tres errores conceptuales. Localízalos y explica en cada caso qué consecuencia tiene.

import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures

X, y = cargar_datos()                      # 40 observaciones

Phi = PolynomialFeatures(degree=39).fit_transform(X)
modelo_a = LinearRegression().fit(Phi, y)
modelo_b = LinearRegression().fit(X, y)

error_a = np.mean((y - modelo_a.predict(Phi)) ** 2)
error_b = np.mean((y - modelo_b.predict(X)) ** 2)

print("gana el modelo a" if error_a < error_b else "gana el modelo b")
  1. Los dos errores se miden sobre los mismos datos con los que se ha ajustado. No son estimaciones de nada: por Teorema 2.1, el modelo de grado 39 sobre 40 puntos puede alcanzar error cero. La comparación está decidida antes de empezar. Hace falta separar un conjunto que no se use para ajustar.
  2. Grado 39 con 40 observaciones es interpolación. No es un error de programación sino de diseño: se está eligiendo a propósito la clase de modelos que garantiza error de entrenamiento nulo, que es justo la que no aprende la señal.
  3. El criterio de decisión es el error de entrenamiento. Aunque los dos puntos anteriores se arreglasen, quedarse con el menor de dos errores medidos sobre los mismos datos favorece sistemáticamente al modelo más complejo. La decisión tiene que apoyarse en datos no usados para ajustar.

(Un cuarto defecto menor, que no cuenta como error conceptual: no se fija una semilla, de modo que el resultado no es reproducible.)
