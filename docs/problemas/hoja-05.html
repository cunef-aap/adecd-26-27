Hoja 5

Hoja del capítulo 5, Preparar datos sin contaminar la evaluación. El capítulo ocupa dos semanas, así que la hoja se reparte entre las dos sesiones de problemas, y cada bloque tiene ejercicios de las dos mitades. Los cuatro primeros bloques tienen la estructura del examen.

Ejercicio 10 Este fragmento pretende preparar los datos y evaluar un modelo. Contiene tres errores conceptuales. Localízalos y explica la consecuencia de cada uno.

import pandas as pd
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

datos = pd.read_csv("airbnb_madrid.csv")

datos = pd.get_dummies(datos)
datos = datos.fillna(datos.median(numeric_only=True))
X = StandardScaler().fit_transform(datos.drop(columns=["price"]))
y = datos["price"]

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25)

modelo = LinearRegression().fit(X_train, y_train)
print("riesgo en test:", ((y_test - modelo.predict(X_test)) ** 2).mean())
