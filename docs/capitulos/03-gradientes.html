3  Gradientes y descenso de gradiente

Cómo se minimiza una función cuando la rejilla no cabe en el universo

Abre el cuaderno para completar en clase en Google Colab.

Por qué estamos aquí

El capítulo 2 dejó el problema planteado: minimizar \(\hat{R}(\boldsymbol{w})\). El capítulo 1 dejó claro que por fuerza bruta no se puede. Aquí construimos la herramienta.

Lo que usamos de antes

Definición 2.1, Teorema 2.1, Corolario 2.1.

Derivadas parciales y gradiente

Definición 3.1 (Derivada parcial) \(\displaystyle \frac{\partial f}{\partial w_j}(\boldsymbol{w}) = \lim_{h \to 0} \frac{f(\boldsymbol{w}+ h\,\mathbf{e}_j) - f(\boldsymbol{w})}{h}\).

Proposición 3.1 (Receta de cálculo) Para derivar respecto de \(w_j\), tratar las demás coordenadas como constantes y aplicar cálculo de una variable.

Definición 3.2 (Gradiente) \(\nabla f(\boldsymbol{w}) = \left( \frac{\partial f}{\partial w_0}, \dots, \frac{\partial f}{\partial w_{p}} \right)^{\mathsf{T}}\).

Proposición 3.2 (Aproximación de primer orden) \(f(\boldsymbol{w}+ h\mathbf{u}) = f(\boldsymbol{w}) + h\, \mathbf{u}^{\mathsf{T}}\nabla f(\boldsymbol{w}) + o(h)\).

Teorema 3.1 (Dirección de máximo crecimiento) Entre los \(\mathbf{u}\) con \(\left\lVert \mathbf{u} \right\rVert = 1\), la derivada direccional \(\mathbf{u}^{\mathsf{T}}\nabla f\) se maximiza en \(\mathbf{u}^\star = \nabla f/ \left\lVert \nabla f \right\rVert\).

Prueba.

\(\square\)

El gradiente es ortogonal a las curvas de nivel

Se enuncia y se dibuja; no se demuestra (requiere curvas parametrizadas y regla de la cadena multivariante). Es intuición geométrica, no una herramienta que vayamos a usar.

Puntos críticos

Definición 3.3 (Punto crítico, mínimo local y global) \(\boldsymbol{w}^\star\) es punto crítico si \(\nabla\hat{R}(\boldsymbol{w}^\star) = \mathbf{0}\); es mínimo local si existe \(r>0\) con \(\hat{R}(\boldsymbol{w}^\star) \le \hat{R}(\boldsymbol{w})\) para todo \(\left\lVert \boldsymbol{w}- \boldsymbol{w}^\star \right\rVert < r\); global si vale para todo \(\boldsymbol{w}\).

Teorema 3.2 (Condición de primer orden) Si \(\hat{R}\) es diferenciable y \(\boldsymbol{w}^\star\) es mínimo local, entonces \(\nabla\hat{R}(\boldsymbol{w}^\star) = \mathbf{0}\). El recíproco es falso: \(f(w)=w^3\) en \(w=0\).

Prueba.

\(\square\)

El gradiente del riesgo

Teorema 3.3 (Gradiente del riesgo, caso \(p= 1\)) Con \(\hat{y}_i= w_0+ w_1 x_i\), \[ \frac{\partial \hat{R}}{\partial w_0} = -\frac{2}{n}\sum_i (y_i- w_0- w_1 x_i), \qquad \frac{\partial \hat{R}}{\partial w_1} = -\frac{2}{n}\sum_i x_i(y_i- w_0- w_1 x_i). \]

Prueba.

\(\square\)

Descenso de gradiente

Definición 3.4 (Descenso de gradiente) \[\boldsymbol{w}^{(t+1)} = \boldsymbol{w}^{(t)} - \alpha\, \nabla\hat{R}\!\left(\boldsymbol{w}^{(t)}\right).\]

Chodrow tiene una errata en su definición de momentum (Def. 11.2): escribe \(\boldsymbol{w}^{(t+1)}\) a ambos lados. No la hereden si algún día lifteamos ese capítulo.

Proposición 3.3 (El descenso desciende) Si \(\nabla\hat{R}(\boldsymbol{w}) \neq \mathbf{0}\), existe \(\bar{\alpha} > 0\) tal que \(\hat{R}(\boldsymbol{w}- \alpha\nabla\hat{R}(\boldsymbol{w})) < \hat{R}(\boldsymbol{w})\) para todo \(\alpha\in (0, \bar{\alpha})\).

Prueba.

\(\square\)

Proposición 3.4 (Caso cuadrático exacto: los tres regímenes) Si \(\hat{R}(w) = a(w - w^\star)^2\) con \(a > 0\), entonces \[w^{(t)} - w^\star = (1 - 2\alpha a)^t \left( w^{(0)} - w^\star \right).\] Converge si y solo si \(0 < \alpha< 1/a\); monótonamente si \(\alpha< 1/2a\); oscilando si \(1/2a < \alpha< 1/a\); diverge si \(\alpha> 1/a\).

Prueba.

\(\square\)

Proposición 3.4 no es una curiosidad: es el andamio con el que el capítulo 5 justifica la estandarización sin necesidad de autovalores. No la corten.

Lo que no explicamos aquí

Teoría de convergencia (suavidad de Lipschitz, tasas), momentum, Adam, planificadores de tasa de aprendizaje. Se nombran, se usan cuando haga falta, y se estudian en un curso de optimización.

Laboratorio

import torch


class DescensoGradiente:
    def __init__(self, w0, lr=0.01):
        self.w = torch.tensor(w0, dtype=torch.float32)
        self.lr = lr
        self.historia = []

    def paso(self, grad_fn):
        g = grad_fn(self.w)
        self.w = self.w - self.lr * g
        return self.w

La trampa de esta semana

«No converge, subo la tasa de aprendizaje»

Casi siempre es lo contrario. Por Proposición 3.4, pasado \(\alpha= 1/a\) el método diverge, y entre \(1/2a\) y \(1/a\) oscila mientras converge, que es justo lo que parece inestabilidad. Y si las variables tienen escalas muy distintas, no hay ninguna \(\alpha\) buena para todas a la vez: eso se arregla estandarizando, no tocando \(\alpha\).

Ejercicios

Ejercicio 3.1 Con los datos \((1,2), (2,3), (3,5)\), \(\boldsymbol{w}^{(0)} = (0,0)\) y \(\alpha= 0{,}1\), ejecute dos iteraciones de descenso de gradiente a mano usando Teorema 3.3.

Ejercicio 3.2 Para \(\hat{R}(w) = 3(w-2)^2\), determine el rango de \(\alpha\) que converge, el que converge monótonamente y el que diverge. Compruébelo numéricamente.

Qué llevarte

  • La condición de primer orden (Teorema 3.2) es lo que convierte «minimizar» en «resolver una ecuación». De ella sale todo el capítulo 4.
  • El descenso siempre desciende para \(\alpha\) suficientemente pequeña (Proposición 3.3), y en el caso cuadrático sabemos exactamente cuánto (Proposición 3.4).
